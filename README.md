# Chart.js Hello World

A bar chart and a line chart drawn with [Chart.js](https://www.chartjs.org/) from data written into `app.js`. Open `index.html` in a browser to see them.

## Use It in Django

To chart data from a Django database, follow Add a Chart in [Django Hello World](https://github.com/CMU-12780/django-hello-world#add-a-chart).
